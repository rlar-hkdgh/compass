# IT 추천 활동 수집 — V10

기본 비활성화. 실제 수집·Preview/Apply·DB 적재는 이번 작업에서 실행하지 않았다. tests는 저장된 HTML/합성 XLSX와 격리된 테스트 DB를 사용한다.

- 수업: 검토한 공식 2026-2 한국어 시간표 XLSX를 읽어 독립 course_activity로 저장 준비. 학수번호·분반의 앞자리 0과 개설학과 코드 유지. 학과 코드를 학생 학적 코드로 해석하지 않는다. 원본 파일 변경 없음.
- 비교과: -Dodream 선택 시 공개 목록에서 IT 제목 후보를 찾고 상세의 IT 내용·학부생 대상·원본 ID를 검증. 마지막 페이지까지 탐색하며 페이지·전체 건수 제한 없음. 기관 접두어에만 SW가 있는 항목 제외. 제목에 IT 키워드가 없는 실제 프로그램은 누락될 수 있다.
- 인턴: -JobCenter 선택 시 추천채용 목록의 인턴 후보를 상세 직무명으로 재검증. 회사 소개에만 IT 문구가 있는 마케팅 직무는 제외. 마지막 페이지까지 탐색하며 페이지·전체 건수 제한 없음. 채용 기업을 provider_name에 넣고 실제 직무·지원 조건·안내는 description에 보존.
- 부트캠프: -Bootcamps 선택 시 코드잇·솔데스크 공개 목록에서 IT 과정 선별 후 상세 본문·신청/교육 기간을 읽는다. 두 기관과 계획 파일의 후보 모두 전체 건수 제한 없이 처리한다. 다른 출처는 기존 검토 상세 URL 방식 유지.
- 자격증: 웹 수집기·파일 입력 기능 제거. 기본 정보·접수/시험 일정 모두 관리자 수동 SQL. 수집 계획의 CERTIFICATION 유형은 거부한다. 자격증 기본/일정에 URL을 저장하지 않는다.

모든 HTTP 요청 간격 3초. 허용 HTTPS 호스트/경로 검증, 응답 크기 제한, 로그인/필수 영역 누락/리디렉션/HTTP 오류 시 중단, 중복·반복 페이지 검사 유지. robots 선행 조회·중단 로직은 사용자 요청대로 없다. 자동 로그인·신청·첨부 수집·OCR·재시도·스케줄러 없음.

일반 활동은 career_activity 한 테이블만 갱신한다. DTO의 IT 근거는 필터 검증용이며 별도 DB 컬럼이 아니다. 원문과 설명을 중복 저장하지 않는다. 유형별 detail/metadata JSON은 저장하지 않는다. 수업 DTO의 detail은 독립 수업 컬럼에 매핑하는 임시 입력이다.

두드림은 상세의 활동 운영 time과 접수 time을 구분해서 읽으며 여러 회차가 모호하면 확정하지 않는다. 인턴은 #edate의 명확한 한국 시각을 접수 마감으로 읽고, 명확한 4자리 연도의 인턴 기간만 활동 날짜로 읽는다. 미확인 날짜를 추정하거나 접수 가능으로 해석하지 않는다. 그 밖의 날짜 안내는 본문에 남긴다. 수업 개설 학기에서 실제 시작일을 추정하지 않는다.

scripts/collect-activities.ps1의 -Plan, -PreviewFile 필수. 수업은 -Workbook/-CourseSourceUrl, 목록 탐색은 -Dodream, -JobCenter로 선택한다. 자격증 옵션 없음. 빈 targets 배열은 파일/목록 어댑터만 처리할 때 사용한다. 계획 상세 target의 기존 구조는 유지하되 detail은 programId/companyName 등 원본 식별 힌트만 허용한다.

Preview도 네트워크와 DB validate를 사용하므로 실행 요청 전에는 사용하지 않는다. Flyway는 수집 명령에서 비활성화하며 V9·V10 적용 검증은 별도다. 기존 미리보기 파일을 덮어쓰지 않는다. 모든 파싱·입력 검증 후에 항목별 저장하며 Apply 후반 실패 시 앞선 활동 저장분은 남을 수 있다. 비밀번호는 기존 숨김 입력/환경변수 방식을 유지하고 파일에 기록하지 않는다.


## 코드잇·솔데스크 목록 어댑터 — V11 출처 코드 필요, 미적용

- 새 테이블/컬럼 없이 CODEIT_SPRINT, SOLDESK 출처 코드만 V11로 추가한다. 기존 마이그레이션 수정 없음. 실제 DB에 V11을 적용하지 않았다.
- 코드잇: https://sprint.codeit.kr/ 의 admissions 숫자 ID 카드만 탐색한다. IT 서비스 창업·프로덕트 디자인·모집 예정은 제외한다. 상세 course-guide의 공식 과정명·모집 일정·교육 기간, 커리큘럼·지원 조건·비용 안내를 읽는다. 카드 교육 기간과 상세가 다르면 중단한다.
- 솔데스크: https://soldesk.com/ 의 상품 카드 중 IT 분야와 총 300시간 이상을 확인할 수 있는 장기 교육만 선별한다. 재직자 단기 주말 강좌는 제외한다. 상세의 prodDetailPC HTML 템플릿을 텍스트로 읽으며 브라우저/JS/이미지/OCR를 실행하지 않는다. 기초교육과 본 교육을 구분해 본 교육일정만 저장한다. Product URL·제목과 개강일도 대조한다.
- 신청 기간이 명시되면 읽고, 미게시 값은 NULL로 둔다. 솔데스크 검증 샘플에는 신청 기간이 없다. 기초교육 시작일을 신청 시작일로 대신 넣지 않는다. 날짜만 공개된 접수 기간은 KST 시작일 00:00:00·마감일 23:59:59로 날짜 경계를 정규화한다. 이는 기관이 명시한 정확한 마감 시각이라는 의미가 아니며 원문을 본문에 보존한다. 명시된 24시간제 시각은 우선 적용한다.
- 확인 불가능한 교육 기간, 이미 시작한 교육·지난 신청 마감은 추천 후보에서 제외한다. 알 수 없는 날짜는 추정하지 않는다. 솔데스크 상품 ID는 현재 페이지의 모집 내용을 갱신하는 키로 사용하며, 공개되지 않은 별도 기수를 만들어 내지 않는다.
- 목록·상세·최종 후보·계획의 전체 건수 제한은 없다. 한 과정이 여러 링크로 나타나면 ID로 중복 제거한다. HTTP 간격 3초와 기존 기본 비활성화 유지. 두 호스트만 응답 상한 4MB(실제 솔데스크 목록이 2MB를 초과); 그 외는 기존 2MB 유지.
- 테스트는 저장 HTML/합성 반례와 격리 DB를 사용하며 실제 수집·Preview/Apply·DB 적재는 실행하지 않는다. -Bootcamps를 실제 실행하려면 V9~V11 적용 상태를 별도로 확인해야 한다.

전체 건수 제한 제거: 유형별 건수·계획 target 수·부트캠프 카드 수 제한을 제거했다. 요청 간격 3초, 중복 검사, 반복 페이지 감지, 응답 크기 제한은 유지한다. 페이지 상한과 MaxPages 옵션은 제거했으며 목록에서 다음 페이지가 없을 때까지 순서대로 탐색한다. 인턴 후보가 없는 페이지도 전체 공고 ID로 반복 여부를 검사한다.
