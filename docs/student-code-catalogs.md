## 전공 62개

- 이름·대학 범위는 학교 학과 전체보기와 기존 2026-2 공식 한국어 시간표 조사 결과를 대조한 초기 후보다. 완전한 학생 학적 전공 마스터라고 주장하지 않는다.
- 아래 숫자는 공식 시간표의 **개설학과코드**다. 학생 **학적 전공코드**와 같은지는 미확정이다.
- 제안: 학교 시스템 연동 없이 학생이 직접 선택하는 서비스 목록의 키로 이 개설학과코드를 사용하되, 학적 코드로 표기하거나 수업 기록으로 학생 전공을 추정하지 않는다. 이 의미의 사용을 결정한 뒤에만 적재한다.
- 3513 컴퓨터공학과를 사용하고 구 소속 3210은 제외했다. 교양 운영 조직/대학 자체/유형2 모집 계열/2027 신설 체계는 제외했다.
- 학부와 세부 전공은 원문대로 구분한다. 동일 명칭만으로 서로 다른 코드를 합치지 않는다.
- 새 명칭 국제일본학전공·에너지자원공학과는 이름의 공식 근거가 있으나 현재 확보된 코드와의 동일성은 미확정이므로 이번 숫자 후보에 임의 연결하지 않았다. 연계·융합전공은 모집 상태와 코드 대응을 확정한 뒤 별도로 추가한다.

## 자격증 9개

서비스가 IT 취업을 대상으로 하므로 첫 목록은 국내 개발·데이터·서버·네트워크 자격으로 제안한다. 전체 자격증 목록은 아니며, 해외/클라우드/비IT 자격 추가 범위는 별도 결정한다.

아래 `code`는 **서비스 내부 식별자 제안**이다. QNET 뒤 숫자만 Q-net 종목코드이며 나머지를 통일된 국가 공식 코드라고 주장하지 않는다.

별도 급수/등급 컬럼은 추가하지 않는다. 리눅스마스터 1급과 2급은 선택할 자격증 종류를 구분하기 위해 각각 다른 명칭/코드로 제안했다. 등급까지 구분하지 않으려면 이 둘을 한 종류로 합치는 결정을 먼저 한다.
